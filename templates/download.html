        Before you upload it

        1. Open the file once. Tap it in your downloads and look at it full size. A file that is technically correct can still be the wrong crop.
        2. Check the name. Some portals reject spaces or brackets in the file name. Rename to plain letters if yours has any.
        3. Upload on the form, not in a chat app. Sending the file to yourself on WhatsApp re-compresses it and the KB size you just set will change.
        4. Keep the original. If the portal rejects this one you will want the full-size photo again, not the resized copy.
